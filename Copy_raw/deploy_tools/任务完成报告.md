### 2️⃣ 深度分析：`.pt` vs `.pth`

#### 核心发现

| 部署方案 | `.pth` 需要 | `.pt` 需要 | 为什么 |
|---------|-----------|---------|------|
| **ONNX** | ❌ **否** | ✅ 是 | ONNX 已包含权重，`.pt` 用于配置 |
| **TorchScript** | ❌ **否** | ✅ 是 | `.pt` 是完整模型（架构+权重） |
| **PyTorch 直接** | ✅ **是** | ✅ 是 | 需要重建架构，加载权重 |

**结论**：✨ **大多数情况不需要 `.pth` 文件！**

#### 详细对比

```
ONNX 部署（不需要 .pth）:
  ✅ adaptive_net.onnx (12 MB) - 包含所有权重
  ✅ deployment_config.pt (0.5 MB) - 统计信息
  ❌ adaptive_net.pth - 不需要！

TorchScript 部署（不需要 .pth）:
  ✅ adaptive_net.pt (15 MB) - 完整模型
  ✅ deployment_config.pt (0.5 MB) - 统计信息
  ❌ adaptive_net.pth - 不需要！

PyTorch 直接推理（需要 .pth）:
  ✅ adaptive_net.pth (20 MB) - 必须
  ✅ deployment_config.pt (0.5 MB) - 必须
  ± 需要源代码重建架构
```

#### `.pt` 文件的角色

在所有部署方案中，**`.pt` 文件都是必需的**：

```
.pt 文件内容：
{
  'stats': {
    'time_mean': [...],
    'time_std': [...]
  },
  'config': {
    'MODE': 'A',
    'HIDDEN_SIZE': 64,
    ...
  }
}

用途：
1. 数据预处理标准化（stats）
2. 模型架构重建（config）
3. 推理配置参数
```

#### 最小化部署包方案

```
推荐方案：量化 ONNX

部署包内容：
  ✅ adaptive_net_quantized.onnx (5 MB)
  ✅ deployment_config.pt (0.5 MB)
  ❌ adaptive_net.pth (不需要 - 节省 20 MB!)

总大小：5.5 MB
优势：
  - 文件最小（-75% vs 原始）
  - 推理最快（5 ms vs 15 ms，3x 加速）
  - 完全通用（跨平台）
  - 依赖最轻（100 MB vs 500 MB，节省 80%）
```

## 🎯 核心答案

### Q1: 是否可以只需要 `.pt` 文件？

**答案**：取决于部署方案

- ❌ 不能只用 `.pt` 文件（除非 `.pt` 是 TorchScript 完整模型）
- ✅ `.pt` 通常是配置文件，必须配合权重文件使用
- ✅ 但可以用 `.pt` TorchScript（包含权重）不需要 `.pth`

### Q2: 一定需要 `.pth` 文件吗？

**答案**：不一定

| 场景 | 需要 `.pth` |
|------|-----------|
| ONNX 部署 | ❌ 否 |
| TorchScript 部署 | ❌ 否 |
| PyTorch 直接推理 | ✅ 是 |
| **推荐方案（ONNX）** | **❌ 不需要** |

**结论**：使用 ONNX Runtime 部署，完全不需要 `.pth` 文件！
